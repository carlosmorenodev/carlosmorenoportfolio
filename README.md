# 🚀 Carlos Moreno Portfolio

¡Bienvenido al repositorio de mi portafolio personal! Este proyecto es una muestra de mis habilidades como desarrollador, donde expongo mis proyectos más destacados, tecnologías que domino y mi experiencia en el desarrollo web.

## 💻 Tecnologías Utilizadas

Esta portafolio ha sido desarrollado utilizando las últimas tecnologías del ecosistema moderno de desarrollo web:

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Librería UI:** [React 19](https://react.dev/)
- **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Iconos:** [Lucide React](https://lucide.dev/) y [React Icons](https://react-icons.github.io/react-icons/)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)

## 📂 Proyectos Destacados

En la sección de proyectos del portafolio podrás encontrar una variedad de trabajos que incluyen, entre otros:

- **Assassins creed Lightbox:** Práctica para hacer lightbox con imagenes de Assassin's Creed.
- **Colección de Cartas animadas:** Cards con animaciones.
- **Clon de Twitter / Tienda Ecommerce:** Proyectos fullstack desarrollados con Next.js.
- **Málaga Weather Dashboard / Weather app:** Aplicaciones del clima con React y Astro.
- Y muchos más mini-juegos y aplicaciones utilizando Vanilla JS, Astro y React.

## 🛠️ Instalación y Uso Local

Si deseas clonar y ejecutar este proyecto localmente, sigue estos pasos:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/carlosmorenodev/carlosmorenoportfolio.git
   cd carlosmorenoportfolio
   ```

2. **Instalar las dependencias:**
   Puedes usar `npm`, `yarn`, `pnpm` o `bun`:
   ```bash
   npm install
   ```

3. **Ejecutar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Abrir en el navegador:**
   Visita [http://localhost:3000](http://localhost:3000) para ver el resultado.
